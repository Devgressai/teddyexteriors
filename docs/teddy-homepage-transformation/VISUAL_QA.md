# Visual QA

Captured per batch. Fill in during Batch 03 onward.

## Capture protocol

For each major batch, after implementation:

1. Run `pnpm dev` locally OR deploy to Vercel preview.
2. Open the homepage.
3. Capture full-scroll screenshots at viewports: 390 (iPhone 14), 768 (iPad portrait), 1440 (standard desktop).
4. Inspect each section for the defects listed in the "Inspect for" checklist below.
5. Record findings in the batch table.
6. Correct, re-capture, mark verified.

## Inspect for

- Weak hierarchy
- Generic components
- Excessive cards
- Repetitive geometry
- Poor image crops
- Awkward whitespace
- Unbalanced sections
- Text density issues
- Broken responsive behavior
- Weak CTA hierarchy
- Visual monotony
- Unintentional alignment
- Cheap-looking shadows
- Excessive rounded corners
- Poor transitions
